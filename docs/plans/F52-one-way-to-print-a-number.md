## 1. 量出來的樣子

=========  ==========  ==========  ==========  ==========  =========
值          結果表/Why   特徵表       Gallery     儀表面板     影像標記
=========  ==========  ==========  ==========  ==========  =========
66.1163    66.12       66.116      66.1        66.116      66
1234.5     **1234**    1234.500    1.23e+03    1.23e+03    1234
99.995     **100**     99.995      100         99.995      100
0.000312   0.000312    0.000312    0.000312    0.000312    **0.00**
3.14159    3.142       3.142       3.14        3.142       3.1
=========  ==========  ==========  ==========  ==========  =========

六個各自寫的函式，沒有一個共用：

| 住哪 | 規則 |
|---|---|
| `results_table` 的 DisplayRole ＋ 徽章 tooltip | `%.4g` |
| `why_panel._fmt` | `%.4g`（**抄的第二份**，同規則不同函式）|
| `widgets._fmt_number` → 單顆特徵表 | 整數捷徑 ＋ `%.3f` ＋極小值 `%.3g` |
| `gallery._fmt_score` → 縮圖說明 | 整數捷徑 ＋ `%.3g` |
| `inspectors._fmt` → 儀表面板 | `%.3g` / `%.3f` / `%.1f` 三段 |
| `inspectors._short_number` → 畫在影像上 | `%.0f` / `%.1f` / `%.2f` 三段 |

⚠ `gallery._fmt_score` 與 `widgets._fmt_number` 是**同一份抄兩次然後漂開的**
—— 前六行一字不差（`bool` / `NaN` / `∞` / 整數捷徑），第七行開始分岔。
這個 repo 記過三次的那個形狀。

### 三個真的會出事的

1. **`99.995` 在結果表寫 `100`、在單顆特徵表寫 `99.995`。**
   使用者在 Results 看到一顆是 100，點進去變成 99.995 —— 他會以為自己點錯顆。
2. **`1234.5` 一邊丟掉 `.5`、一邊補三位假精度**（`1234.500`）。
   一個丟資訊、一個發明資訊，方向剛好相反。
3. **`0.000312` 畫在影像上是 `0.00`** —— 那讀起來是**零**，而影像上的標記
   正是使用者盯著看的地方。

## 2. 修法：`ui/numbers.py`，一支 `format_feature_value`

* `None` → 空字串（不是 `None` 那四個字，F30）；
* `True`/`False` → `Yes`/`No`；
* 整數 → 不拖小數；
* 其他 → **5 位有效數字**。

五個顯示點（結果表、特徵表、Gallery、儀表、Why）全部改成它的別名。

### ⚠ 提案寫 `%.4g`，實作時算過發現那是錯的

第一版的理由是「它已經是最多地方在用的那一份」。**算一次就知道不對**：
`%.4g` 把 `99.995` 印成 `100` —— 那正是上面第 1 條的危害。統一到一個會誤導
的寫法上，只是把不一致換成**一致地錯**。

`%.5g` 讓 `99.995` 與 `1234.5` 都完整留著，而且仍然比 `%.6g` 短。

> **統一之前先算一次。** 挑「最多人用的那一份」是一個看起來安全、實際上沒有
> 檢查過的判準。

### 影像上的短版是刻意的例外，而例外有邊界

`format_feature_value_short` 留著（10 px 高的字，`SNR 66` 比 `SNR 66.116`
好讀），但：

* **只有畫在影像上的標記可以用它** —— 有一條測試掃全 `ui/`，用的人只准是
  `inspectors.py`；
* **極小值退回有效位數** —— 修掉 `0.000312 → 0.00` 那個 bug。
  「0.00」跟「太小所以看不出來」是兩句完全不同的話。

### 座標軸刻度不算

直方圖 x 軸的 lo/hi 仍然自己挑位數，而那是對的：軸標要的是短的整數。
它進了一張 `_AXIS_LABEL_ALLOWLIST`，**而那張表配著一支反向測試** ——
`CLAUDE.md` 的那一課：任何例外清單都要有那支反向的測試，不然它就是一張
只會變長的紙。

## 4. 為什麼「值一樣」不夠

`test_every_place_prints_the_same_string` 比的是值 —— 而兩份實作在某些值上
剛好同意是常態（上面那三次抄兩份，每一次都是從「現在看起來一樣」開始的）。
所以另外一條看的是**出處**：那幾支要真的呼叫共用的那一支。
